#Student Management System

### A C Programming Project Using Structures and File Handling

---

## About the Project

The **Student Management System** is a menu-driven application developed using the C programming language. It is designed to manage student information, course details, fee payments, and academic results.

The project demonstrates important C programming concepts such as structures, arrays, functions, and file handling.

## Key Features

- Admin Login System
- Add New Student Records
- Display Student Information
  Manage Student Fees
- Manage Course Details
- Store and Manage Student Results
- Save and Load Records Using File Handling

##  Technologies Used

| Technology | Purpose |
|---|---|
| C Programming | Core programming language |
| Structures | Store student information |
| Arrays | Manage multiple records |
| File Handling | Save and retrieve student data |
| Functions | Organize program operations |

## How to Run the Project

1. Download or clone this repository.
2. Open the '.c' file in Dev-C++ or another C compiler.
3. Compile the program.
4. Run the generated application.
5. Follow the menu displayed on the screen.
